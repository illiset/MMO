# Reference images (mood boards)

One folder per zone, named by the zone id used in `data/zones/` (e.g. `dal-riata`, `sidhe`,
`germanic`, `alfar`, `hillback`, `baltic`, `slavic`, `severus`, `romance`, `mythic`, `hellenic`,
`armenian`, `woodling`, `gobbledrift`, `fae`, `centaur`). Optional sub-folders per topic inside a
zone (`forest/`, `castle/`, `weather/`, `village/`).

Rules: mood-board use only, never shipped in the game; keep images under ~5 MB each; any file name
is fine. Claude reads these folders when dressing a zone.
